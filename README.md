# -The-Empowered-Study-Navigator
The Empowered Study Navigator is a full-stack AI academic platform built with Python, Flask, MySQL, and Tailwind CSS for student-teacher performance tracking. It uses Scikit-Learn Random Forest models to predict academic risk and analyze interests, plus a LangChain, Hugging Face, FAISS, and Groq LLM RAG assistant for real-time PDF Q&amp;A.
